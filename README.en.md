# h_boot

#### Description

**1、h-boot**
Description: h-boot is a rapid development platform for backend programs of SpringBoot+Vue separated frontend and backend. It is based on SpringBoot 3.5+, MyBatisPlus 3.5+, MySQL 8+, and JDK 17+
